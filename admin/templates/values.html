Manage tile thumbnails

One row per value currently offered as a guided filter tile on the home page. Paste a cover image URL and hit Save to curate it - writes straight to app/tile_thumbnails.py, no hand-editing required. A blank row is showing the automatic fallback image (borrowed from a matching catalog item), not an error - see the warning box above for which ones those are. Leaving the URL field blank and saving does nothing (an already-curated entry isn't cleared this way - edit app/tile_thumbnails.py by hand for that, same "no delete via this form" philosophy as the value lists below). Check Hidden and hit Save to remove a tile from the home page's guided filter grid entirely (writes to app/hidden_tiles.py) - the value stays fully filterable through its chip in "Erweiterte Filter" either way, this only declutters the tile view. Uncheck and Save again to bring it back.

Value lists

The fixed vocabularies genre/franchise/seasonal/award draw from - used to validate overrides.py entries (a value outside these lists just logs a warning, never fails a sync - see refresh.py) and to populate the dropdowns on the Suggestions screen. Adding a genre/franchise/seasonal value here also adds its German and English display label to app/i18n.py - without that step a new value would still work for filtering but show its raw slug instead of a translated label everywhere it's displayed. Award names are shown as-is, so they need no label. There's no delete here - edit refresh.py/app/i18n.py by hand for that, same philosophy as everywhere else in this tool.

Value lists

The fixed vocabularies genre/franchise/mood/seasonal/award draw from - used to validate overrides.py entries (a value outside these lists just logs a warning, never fails a sync - see refresh.py) and to populate the dropdowns on the Suggestions screen. Adding a genre/franchise/mood/seasonal value here also adds its German and English display label to app/i18n.py - without that step a new value would still work for filtering but show its raw slug instead of a translated label everywhere it's displayed. Award names are shown as-is, so they need no label. There's no delete here - edit refresh.py/app/i18n.py by hand for that, same philosophy as everywhere else in this tool.

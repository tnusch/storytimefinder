Check Removed

Enumerates every active source's current items via YouTube's playlistItems.list (cheap, 1 unit/page) and stages that id list into data/fetched_items.json - this is what Sync uses to delete items no longer returned by their source, and what Fetch reads to find new items without enumerating anything itself. Runs refresh/refresh.py --check-removed as a subprocess, using this machine's .env for API keys. Never touches storytimefinder.db, catalog.json, or Claude. Run this on its own schedule - at most every 30 days, weekly recommended - independently of how often you run Fetch.

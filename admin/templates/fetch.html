Fetch

Pulls new items' metadata from YouTube and a Claude suggestion for each, staging both into data/fetched_items.json and data/claude_suggestions.json. Runs refresh/refresh.py --fetch as a subprocess, using this machine's .env for API keys. Prefers the current-item-id list a prior Check Removed run staged over calling YouTube's playlistItems.list itself, but works standalone too - a source with no Check Removed data yet is simply checked on the spot as a one-time fallback, no need to run Check Removed first. Never touches storytimefinder.db or catalog.json - nothing here is visible on the live site until you run Sync afterward. This can take a while for many new items - the page waits for it to finish before showing output. To regenerate a single item's suggestion, use its Regenerate suggestion button on the Suggestions screen instead.

Sync

The final step: rebuilds storytimefinder.db and catalog.json from whatever the most recent Fetch staged, plus whatever's currently in overrides.py. Runs refresh/refresh.py --sync as a subprocess. Never calls the YouTube or Claude APIs - safe to run as often as you like after editing overrides.py, with no extra API cost. A source with no prior fetch is skipped (not deleted) - see the output below if that happens. --clean-db lives on the Fetch screen only - paired with Sync alone (no fresh Fetch first) it can leave the catalog empty, with no real upside, so it isn't offered here.
